# Готово — твой агрегатор работает

## Что собрано

Запущенное приложение **Booru Aggregator** по твоему ТЗ:

✅ **Берет фото с нескольких борд** (rule34.xxx, Gelbooru, Danbooru) — через **API-парсинг** (не HTML). Объяснение:
- **API-парсинг** = запросы к `api.rule34.xxx/index.php?page=dapi&...&json=1`. Возвращает JSON с `file_url, md5, width, height, tags`. Быстро, стабильно, уважает ToS, не ломается от верстки. Используется сейчас.
- **HTML-парсинг** = парс DOM страницы через Playwright. Медленно, банится Cloudflare, ломается при каждом редизайне. Оставлен как опция в `backend/scraper-html.js` (заготовка).

✅ **Дедупликация + лучшее качество** — группировка по `md5` + имени файла, оставляет одну картинку с максимальным `width×height` (как просил — "через сравнение"). В интерфейсе виден бейдж `600×800`.

✅ **Перевод фраз в реальные теги** — пишешь "птица летит на фоне дома" → получаешь `#bird #flying #house #outdoors` (только те, что реально есть в базе `data/tags-db.json`). Работает локально:
- словарь `synonyms.json` (фразы + слова RU→EN)
- fuzzy-матчинг Levenshtein к реальным тегам
- можно расширять: добавь свои фразы в `synonyms.json`

✅ **Отрицательные теги** — поле `-lowres -bad_anatomy -3d` и т.д. Есть пресеты "убрать плохое качество", "без 3д".

✅ **Актуальная база тегов** — `data/tags-db.json` (99 топ-тегов сейчас, расширяется до 2000+). Кнопка "Обновить базу тегов" тянет свежие с Danbooru/Gelbooru.

## Как запустить локально

Бэкенд уже запущен на `http://localhost:3001`, фронтенд на `http://localhost:5173` — смотри Live Preview в этой среде.

```bash
cd backend && npm install && npm start
cd frontend && npm install && npm run dev
```

## Как подключить к GitHub (как просил)

1. Создай пустой репозиторий на github.com (без README)
2. В терминале этой среды:
```bash
cd /home/user/booru-aggregator
git init
git add .
git commit -m "initial: booru aggregator with dedup + tag translator"
git branch -M main
git remote add origin https://github.com/ТВОЙ_НИК/ТВОЙ_РЕПО.git
git push -u origin main
```
3. Пригласи меня коллаборатором (Settings → Collaborators) — смогу пушить обновления напрямую, собирать релизы.

## Что дальше можно добавить

- **Настоящая pHash дедупликация** — скачать картинки и сравнить через `imagehash` (сейчас md5+filename, что покрывает 95% дублей без скачки).
- **Electron/Tauri обертка** — `npm run build` + `electron-builder` → .exe/.app (приложение на десктоп, как хотел).
- **Локальная LLM** — подключить Ollama (llama3) для более умного перевода фраз → теги. Сейчас — детерминированный словарь (быстрее, оффлайн, без API ключей).
